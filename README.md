 🪨 Rock Paper Scissors Game

A simple *Rock Paper Scissors* game built with *HTML, **CSS, and **JavaScript*.  
Play against the computer, track your score, and enjoy a clean, responsive design.

---

 🎮 Features
- Interactive buttons for Rock, Paper, and Scissors  
- Real-time score updates (Win, Lose, Tie)  
- Reset score option  
- Lightweight, beginner-friendly JavaScript logic  

---

 🧠 What I Learned
- Working with JavaScript functions and event listeners  
- Updating the DOM dynamically  
- Using localStorage to save score  
- Practicing CSS layout and styling  

---

🧩 Technologies Used
- HTML5  
- CSS3  
- JavaScript (Vanilla JS)

---

🚀 How to Play
1. Click *Rock, **Paper, or **Scissors*.  
2. The computer randomly chooses its move.  
3. See who wins — your score updates instantly.  
4. Click *Reset Score* to start fresh.
